## परिचय और अवलोकन

यह एप्लिकेशन एस्पेरांतो पाठ को चीनी अक्षरों (कान्जी) या रूबी एनोटेशन के साथ HTML में परिवर्तित करने के लिए एक Streamlit-आधारित वेब उपकरण है। यह Python में विकसित किया गया है और क्लाउड पर होस्ट किया गया है। अनुप्रयोग की मुख्य कार्यक्षमताएँ हैं:

1. **पाठ प्रतिस्थापन**: एक JSON प्रतिस्थापन नियम फ़ाइल का उपयोग करके एस्पेरांतो शब्दों को चीनी अक्षरों में परिवर्तित करना
2. **HTML रूबी एनोटेशन**: उच्चारण सहायता के लिए HTML में रूबी टैग (छोटे अक्षरों में व्याख्या) जोड़ना
3. **प्रतिस्थापन JSON जनरेटर**: कस्टम प्रतिस्थापन नियमों के साथ जेसन फ़ाइलें बनाना
4. **समानांतर प्रसंस्करण**: बड़े पाठों के लिए बहु-प्रक्रिया (multiprocessing) समर्थन

यह सिस्टम तीन प्रकार के प्रतिस्थापन का समर्थन करता है:
- **वैश्विक प्रतिस्थापन**: संपूर्ण पाठ में प्रतिस्थापन
- **स्थानीय प्रतिस्थापन**: `@` चिह्नों के बीच चिह्नित पाठ का प्रतिस्थापन
- **प्रतिस्थापन से छूट**: `%` चिह्नों के बीच चिह्नित पाठ को प्रतिस्थापन से बचाना

## अनुप्रयोग संरचना

अनुप्रयोग निम्नलिखित प्रमुख घटकों से बना है:

1. **फ्रंटएंड (UI)**: Streamlit द्वारा प्रबंधित - फॉर्म, बटन, फ़ाइल अपलोडर, और परिणाम प्रदर्शन
2. **बैकएंड प्रसंस्करण इंजन**: पाठ प्रतिस्थापन और प्रारूपण लॉजिक
3. **JSON निर्माण उपकरण**: कस्टम प्रतिस्थापन नियमों को बनाने के लिए एक अलग पृष्ठ
4. **डेटा संग्रहण**: जेसन और टेक्स्ट फ़ाइलों का उपयोग अनुवाद सूची और प्लेसहोल्डर्स के लिए

वास्तुशिल्प दृष्टिकोण:

```
[उपयोगकर्ता] <--> [Streamlit UI] <--> [प्रसंस्करण इंजन] <--> [फ़ाइल प्रणाली]
                      |
                      +--> [JSON निर्माण उपकरण]
```

## मुख्य कोड फाइलें और उनकी भूमिकाएँ

प्रणाली चार मुख्य Python फ़ाइलों से बनी है:

यह मुख्य अनुप्रयोग फ़ाइल है जो Streamlit इंटरफ़ेस प्रबंधित करती है और प्रक्रिया प्रवाह नियंत्रित करती है। प्रमुख कार्य:

- Streamlit UI घटकों का प्रबंधन (फॉर्म, सेलेक्ट बॉक्स, अपलोडर, आदि)
- JSON और प्लेसहोल्डर फ़ाइलों का लोडिंग
- उपयोगकर्ता इनपुट को संसाधित करना और डेटा प्रवाह को समन्वित करना
- `orchestrate_comprehensive_esperanto_text_replacement()` जैसी मुख्य फ़ंक्शंस को कॉल करना
- समानांतर प्रसंस्करण का प्रबंधन (यदि सक्षम है)
- परिणामों का प्रदर्शन और डाउनलोड विकल्प

### 2. `एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ.py`

यह JSON जनरेटर पृष्ठ है जो Streamlit के "pages" फ़ोल्डर में रहता है। इसके कार्य:

- CSV फ़ाइलों से एस्पेरांतो शब्दमूल और अनुवाद/रूबी डेटा आयात करना

- शब्दमूल विखंडन नियमों को संसाधित करना
- विभिन्न प्रकार के प्रतिस्थापन सूचियों का निर्माण करना
- एक समेकित JSON फ़ाइल उत्पन्न करना

### 3. `esp_text_replacement_module.py`

यह मॉड्यूल मुख्य पाठ प्रतिस्थापन कार्यक्षमता प्रदान करता है। प्रमुख कार्य:

- एस्पेरांतो विशेष अक्षरों का रूपांतरण (ĉ, ĝ, ĥ आदि)
- प्लेसहोल्डर आधारित सुरक्षित प्रतिस्थापन (`safe_replace`)
- विभिन्न प्रतिस्थापन प्रकारों के लिए समेकित कार्यान्वयन
- समानांतर प्रसंस्करण के लिए मल्टीप्रोसेसिंग कार्य
- HTML हेडर और फुटर जोड़ना

### 4. `esp_replacement_json_make_module.py`

यह मॉड्यूल JSON जनरेटर पृष्ठ का समर्थन करता है। प्रमुख कार्य:

- पाठ/रूबी प्रारूपण विकल्प प्रदान करना
- अक्षर चौड़ाई मापन और HTML ब्रेक (`<br>`) डालना
- रूबी टैग कैपिटलाइज़ेशन
- समानांतर JSON निर्माण प्रसंस्करण
- अतिरिक्त रूबी परिवर्तन फ़ंक्शंस

## मुख्य डेटा संरचनाएँ

### JSON प्रतिस्थापन फ़ाइल

यह JSON फ़ाइल तीन प्रमुख प्रतिस्थापन सूचियों से बनी है:

```python
{
    "全域替换用のリスト(列表)型配列(replacements_final_list)": [
        [पुराना_शब्द, नया_शब्द, प्लेसहोल्डर], 
        ...
    ],
    "局部文字替换用のリスト(列表)型配列(replacements_list_for_localized_string)": [
        [पुराना_शब्द, नया_शब्द, प्लेसहोल्डर], 
        ...
    ],
    "二文字词根替换用のリスト(列表)型配列(replacements_list_for_2char)": [
        [पुराना_शब्द, नया_शब्द, प्लेसहोल्डर], 
        ...
    ]
}
```

- **वैश्विक प्रतिस्थापन सूची**: सभी एस्पेरांतो शब्दों के लिए प्रतिस्थापन
- **स्थानीय प्रतिस्थापन सूची**: `@` टैग के अंदर चिह्नित पाठ के लिए प्रतिस्थापन
- **दो-अक्षर प्रतिस्थापन सूची**: एस्पेरांतो प्रत्यय, उपसर्ग, आदि के लिए विशेष नियम

### प्लेसहोल्डर फ़ाइलें

प्रणाली तीन प्रकार के प्लेसहोल्डर्स का उपयोग करती है:

1. **प्रतिस्थापन छोड़ने के लिए प्लेसहोल्डर्स**: `%...%` से चिह्नित पाठ के लिए
2. **स्थानीय प्रतिस्थापन के लिए प्लेसहोल्डर्स**: `@...@` से चिह्नित पाठ के लिए
3. **वैश्विक प्रतिस्थापन के लिए प्लेसहोल्डर्स**: पूरे पाठ में प्रतिस्थापन के लिए

ये प्लेसहोल्डर्स "टोकन" के रूप में कार्य करते हैं जो प्रसंस्करण के दौरान पाठ के भागों को अस्थायी रूप से प्रतिस्थापित करते हैं, फिर बाद में वापस बदल देते हैं।

## कोड विश्लेषण

### सुरक्षित प्रतिस्थापन तंत्र

प्रणाली की मुख्य विशेषता `safe_replace()` फ़ंक्शन है:

```python
def safe_replace(text: str, replacements: List[Tuple[str, str, str]]) -> str:
    """
    (old, new, placeholder) के त्रिक से बने रिप्लेसमेंट लिस्ट लेकर,
    text में old → placeholder → new की चरणबद्ध प्रतिस्थापन करता है।
    """
    valid_replacements = {}
    # पहले old→placeholder
    for old, new, placeholder in replacements:
        if old in text:
            text = text.replace(old, placeholder)
            valid_replacements[placeholder] = new
    # फिर placeholder→new
    for placeholder, new in valid_replacements.items():
        text = text.replace(placeholder, new)
    return text
```

यह महत्वपूर्ण है क्योंकि यह "शब्द में शब्द" समस्या से बचता है - जहां एक प्रतिस्थापन दूसरे के साथ हस्तक्षेप कर सकता है। प्लेसहोल्डर्स का उपयोग करके, यह सुनिश्चित होता है कि प्रत्येक प्रतिस्थापन स्वतंत्र रूप से किया जाता है।

### समानांतर प्रसंस्करण

`parallel_process()` फ़ंक्शन बड़े पाठों के लिए प्रसंस्करण समय को महत्वपूर्ण रूप से कम करता है:

```python
def parallel_process(
    text: str,
    num_processes: int,
    # अन्य पैरामीटर...
) -> str:
    """
    दिए गए text को पंक्ति-दर-पंक्ति विभाजित करके, process_segment को
    मल्टीप्रोसेसिंग से समानांतर रूप से चलाता है और परिणाम जोड़ता है।
    """
    # पंक्तियों में विभाजन
    lines = re.findall(r'.*?\n|.+$', text)
    # प्रत्येक प्रोसेस के लिए पंक्तियों का वितरण
    lines_per_process = max(num_lines // num_processes, 1)
    ranges = [(i * lines_per_process, (i + 1) * lines_per_process) for i in range(num_processes)]
    # मल्टीप्रोसेसिंग पूल बनाएँ और कार्य वितरित करें
    with multiprocessing.Pool(processes=num_processes) as pool:
        results = pool.starmap(process_segment, [...])
    # परिणाम जोड़ें
    return ''.join(results)
```

यह पंक्ति-दर-पंक्ति विभाजन के माध्यम से काम करता है, जिससे प्रत्येक CPU कोर स्वतंत्र रूप से पाठ के अलग-अलग हिस्सों पर काम कर सकता है।

### आउटपुट प्रारूपण

`output_format()` फ़ंक्शन विभिन्न प्रकार के आउटपुट बनाता है:

```python
def output_format(main_text, ruby_content, format_type, char_widths_dict):
    """
    एस्पेरांतो शब्दमूल(main_text) और उसके अनुवाद/कान्जी(ruby_content) को
    निर्दिष्ट format_type के अनुसार संयोजित करता है
    """
    if format_type == 'HTML格式_Ruby文字_大小调整':
        # अक्षर चौड़ाई के अनुसार फ़ॉन्ट आकार समायोजन
        width_ruby = measure_text_width_Arial16(ruby_content, char_widths_dict)
        width_main = measure_text_width_Arial16(main_text, char_widths_dict)
        ratio_1 = width_ruby / width_main
        if ratio_1 > 6:
            return f'<ruby>{main_text}<rt class="XXXS_S">{insert_br_at_third_width(ruby_content, char_widths_dict)}</rt></ruby>'
        # अन्य अनुपात के लिए अन्य फ़ॉर्मेटिंग...
    # अन्य प्रारूप प्रकारों के लिए वैकल्पिक फ़ॉर्मेटिंग...
```

यह फ़ंक्शन अक्षर चौड़ाई की गणना करता है और स्वचालित रूप से फ़ॉन्ट आकार और लाइन ब्रेक (रूबी अनोटेशन के लिए) को समायोजित करता है।

### प्रतिस्थापन JSON का निर्माण

JSON निर्माता पेज पर, कई चरणों में प्रतिस्थापन सूचियों का निर्माण होता है:

1. **अस्थायी प्रतिस्थापन सूची**: CSV डेटा से
2. **वाक्यांश संरचना नियम**: एस्पेरांतो शब्दमूल और भाग-वाचक नियम
3. **विशेष प्रत्यय प्रसंस्करण**: an, on, और फिर क्रिया रूपों के लिए धातुओं
4. **प्राथमिकता आधारित क्रमबद्धन**: लंबे शब्दों को उच्च प्राथमिकता
5. **केस संस्करण**: उचित विकल्प, पूँजीकरण, और लोअरकेस के लिए प्रतिस्थापन

## उन्नत सुविधाएँ

### 1. HTML रूबी फ़ॉन्ट आकार समायोजन

HTML प्रारूप में, सिस्टम स्वचालित रूप से रूबी फ़ॉन्ट आकार को समायोजित करता है:

```html
<ruby>{main_text}<rt class="M_M">{ruby_content}</rt></ruby>
```

जहां CSS क्लास (`XXXS_S` से `XXL_L`) अनुवाद की लंबाई के आधार पर निर्धारित होती है।

### 2. प्लेसहोल्डर-आधारित प्रतिस्थापन

प्रणाली तीन स्तरीय प्रतिस्थापन का उपयोग करती है:

1. **बचाव चिह्नित (%...%)**: प्रतिस्थापन से बचाए गए भाग
2. **स्थानीय प्रतिस्थापन (@...@)**: केवल चिह्नित भाग में प्रतिस्थापन
3. **वैश्विक प्रतिस्थापन**: पूरे पाठ में प्रतिस्थापन

### 3. द्वि-अक्षर शब्दमूल प्रतिस्थापन

एस्पेरांतो में छोटे उपसर्ग और प्रत्यय के लिए विशेष प्रतिस्थापन नियम:

```python
suffix_2char_roots=['ad', 'ag', 'am', 'ar', ...]  # प्रत्यय
prefix_2char_roots=['al', 'am', 'av', 'bo', ...]  # उपसर्ग
standalone_2char_roots=['al', 'ci', 'da', 'de', ...]  # स्वतंत्र शब्दमूल
```

ये स्वतंत्र रूप से प्रसंस्करण किए जाते हैं, जिससे एस्पेरांतो व्याकरण के अनुसार अधिक परिष्कृत प्रतिस्थापन संभव होता है।

## विस्तार और अनुकूलन संभावनाएँ

### कोड विस्तार के सुझाव

1. **नई भाषाओं के लिए समर्थन**: अतिरिक्त CSV स्रोत फ़ाइलों के साथ विभिन्न भाषाओं में अनुवाद जोड़ें
2. **नए आउटपुट प्रारूप**: उदाहरण के लिए, अन्य प्रकार के HTML एनोटेशन या पीडीएफ निर्यात
3. **बेहतर समानांतर प्रसंस्करण**: वाक्य-स्तरीय समानांतरता या GPU समर्थन
4. **एपीआई इंटरफ़ेस**: वेब सेवा के रूप में प्रतिस्थापन प्रदान करें
5. **मशीन लर्निंग**: अनुवाद सुझावों के लिए AI के साथ एकीकरण

### अनुकूलन बिंदु

अनुप्रयोग को निम्न तरीकों से अनुकूलित किया जा सकता है:

1. **CSV प्रारूप अनुकूलन**: अधिक स्तंभों (जैसे संदर्भ, उदाहरण, कठिनाई स्तर) के साथ अपना CSV बनाएँ
2. **अतिरिक्त डिक्शनरी जोड़ें**: अपने स्वयं के शब्दमूल विखंडन नियम बनाएँ
3. **CSS अनुकूलन**: HTML आउटपुट में रूबी अनोटेशन का स्टाइल बदलें
4. **नए प्लेसहोल्डर चिह्न**: विशेष प्रतिस्थापन प्रकारों के लिए अतिरिक्त प्लेसहोल्डर प्रकार जोड़ें
