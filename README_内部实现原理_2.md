# एस्पेरान्तो पाठ प्रतिस्थापन ऐप्लिकेशन: तकनीकी विश्लेषण और कार्यप्रणाली

मैंने आपके एस्पेरान्तो पाठ प्रतिस्थापन ऐप्लिकेशन की आंतरिक कार्यप्रणाली का विस्तृत तकनीकी विश्लेषण हिंदी में तैयार किया है। यह दस्तावेज़ मध्यवर्ती हिंदी-भाषी प्रोग्रामरों के लिए है, जो GUI का उपयोग तो जानते हैं, परंतु अब आंतरिक तंत्र को समझना चाहते हैं।

इस विश्लेषण में निम्नलिखित प्रमुख विषय शामिल हैं:

## 1. ऐप्लिकेशन आर्किटेक्चर
चारों मुख्य Python फाइलों का परिचय और उनके बीच संबंध - `main.py`, `एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ.py`, `esp_text_replacement_module.py`, और `esp_replacement_json_make_module.py`

## 2. मुख्य डेटा संरचनाएँ
प्रतिस्थापन JSON फाइलों का प्रारूप और तीन प्रमुख प्रतिस्थापन सूचियों का विवरण - सार्वभौमिक, स्थानीय, और द्वि-अक्षर प्रतिस्थापन

## 3. मुख्य मॉड्यूल विश्लेषण
प्रत्येक मॉड्यूल के प्रमुख फंक्शन और उनके कार्य का विस्तृत विवरण, प्रमुख कोड अंशों के साथ

## 4. प्रतिस्थापन अल्गोरिदम
सुरक्षित प्रतिस्थापन प्रक्रिया, प्राथमिकता-आधारित प्रतिस्थापन, और HTML रूबी प्रारूपण की तकनीकी विवरण

## 5. समानांतर प्रोसेसिंग
बड़े पाठों के लिए Python के `multiprocessing` मॉड्यूल का उपयोग और उसका कार्यान्वयन

## 6. JSON जनरेटर पेज
JSON फाइल जनरेटर की जटिल प्रक्रिया और उसके विभिन्न चरणों का विश्लेषण

## 7. प्रदर्शन अनुकूलन
ऐप्लिकेशन में प्रयुक्त विभिन्न प्रदर्शन अनुकूलन तकनीकें

## 8. तकनीकी उपयोग सुझाव
प्रोग्रामिंग दृष्टिकोण से उपयोग और अनुकूलन के लिए सुझाव

# एस्पेरान्तो पाठ प्रतिस्थापन ऐप्लिकेशन: तकनीकी विश्लेषण और कार्यप्रणाली

## परिचय

एस्पेरान्तो पाठ प्रतिस्थापन ऐप्लिकेशन एक जटिल Streamlit आधारित अनुप्रयोग है जो एस्पेरान्तो पाठ को कान्जी (चीनी अक्षर) या HTML रूबी एनोटेशन में परिवर्तित करता है। इस दस्तावेज़ में हम ऐप्लिकेशन की आंतरिक कार्यप्रणाली, डेटा प्रवाह, और तकनीकी कार्यान्वयन का विस्तृत विश्लेषण प्रस्तुत करेंगे।

यह दस्तावेज़ उन मध्यवर्ती प्रोग्रामरों के लिए है जो पहले से ही ऐप्लिकेशन के GUI उपयोग से परिचित हैं और अब इसकी आंतरिक कार्यप्रणाली को समझना चाहते हैं।

## ऐप्लिकेशन आर्किटेक्चर: ओवरव्यू

ऐप्लिकेशन चार मुख्य Python फाइलों पर आधारित है:

1. **main.py**: मुख्य Streamlit ऐप्लिकेशन फाइल जो केंद्रीय UI और प्रतिस्थापन कार्यक्षमता प्रदान करती है
2. **एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ.py**: Streamlit के "pages" फोल्डर में स्थित द्वितीयक पृष्ठ जो प्रतिस्थापन JSON फ़ाइलें बनाने के लिए है
3. **esp_text_replacement_module.py**: प्रतिस्थापन फ़ंक्शन और अल्गोरिदम प्रदान करने वाला मॉड्यूल
4. **esp_replacement_json_make_module.py**: JSON जनरेशन से संबंधित फ़ंक्शन और उपकरण प्रदान करने वाला मॉड्यूल

### डेटा प्रवाह ओवरव्यू

ऐप्लिकेशन के प्रमुख डेटा प्रवाह निम्नलिखित हैं:

1. **इनपुट स्रोत**: एस्पेरान्तो पाठ (मैनुअल इनपुट या फाइल अपलोड के माध्यम से)
2. **प्रतिस्थापन नियम**: JSON फ़ाइल से लोड किए गए (डिफॉल्ट या उपयोगकर्ता-अपलोड किए गए)
3. **प्रसंस्करण**: एस्पेरान्तो पाठ का प्रतिस्थापन नियमों के अनुसार रूपांतरण
4. **आउटपुट**: HTML, कोष्ठक प्रारूप, या सरल प्रतिस्थापन में परिवर्तित पाठ

## मुख्य डेटा संरचनाएँ

### प्रतिस्थापन JSON फाइलों का प्रारूप

प्रतिस्थापन JSON फाइल में तीन मुख्य सूचियां होती हैं:

1. **全域替换用のリスト(列表)型配列(replacements_final_list)**: सम्पूर्ण पाठ में सार्वभौमिक प्रतिस्थापन के लिए सूची
2. **局部文字替换用のリスト(列表)型配列(replacements_list_for_localized_string)**: @ चिह्नित क्षेत्रों में स्थानीय प्रतिस्थापन के लिए सूची
3. **二文字词根替换用のリスト(列表)型配列(replacements_list_for_2char)**: दो-अक्षर वाले एस्पेरान्तो शब्द मूलों के लिए विशेष प्रतिस्थापन सूची

प्रत्येक सूची में प्रतिस्थापन नियम टपल के रूप में संग्रहीत होते हैं, प्रत्येक टपल का प्रारूप है:
```
(original_text, replacement_text, placeholder)
```

### प्लेसहोल्डर सिस्टम

ऐप्लिकेशन एक जटिल प्लेसहोल्डर व्यवस्था का उपयोग करता है जो दो-चरण प्रतिस्थापन प्रक्रिया को संभव बनाता है:

1. सबसे पहले, मूल पाठ को अस्थायी प्लेसहोल्डर से प्रतिस्थापित किया जाता है
2. फिर, प्लेसहोल्डर को अंतिम प्रतिस्थापन पाठ से प्रतिस्थापित किया जाता है

यह दृष्टिकोण प्रतिस्थापित होने वाले शब्दों के बीच परस्पर हस्तक्षेप (जैसे "esti" को प्रतिस्थापित करते समय "estas" भी प्रतिस्थापित हो जाना) को रोकता है।

तीन प्रकार के प्लेसहोल्डर फाइलें प्रयोग की जाती हैं:
- `占位符(placeholders)_%1854%-%4934%_文字列替换skip用.txt`: % से चिह्नित क्षेत्रों के लिए
- `占位符(placeholders)_@5134@-@9728@_局部文字列替换结果捕捉用.txt`: @ से चिह्नित क्षेत्रों के लिए
- `占位符(placeholders)_$20987$-$499999$_全域替换用.txt`: सार्वभौमिक प्रतिस्थापन के लिए

## मुख्य मॉड्यूल और क्लास विश्लेषण

### `main.py` - मुख्य ऐप्लिकेशन

`main.py` Streamlit ऐप्लिकेशन का मुख्य एंट्री पॉइंट है। यह निम्नलिखित घटकों को प्रबंधित करता है:

#### प्रमुख फंक्शन:

1. **`load_replacements_lists(json_path)`**: JSON फाइल से तीनों प्रतिस्थापन सूचियों को लोड करता है और कैश करता है (`@st.cache_data` का उपयोग करके)

2. **Streamlit UI कॉन्फ़िगरेशन**: विभिन्न UI घटकों को स्थापित करता है जैसे:
   - `st.set_page_config()`: पेज लेआउट और शीर्षक
   - फॉर्म, इनपुट बॉक्स, डाउनलोड बटन, आदि

3. **प्रोसेसिंग लॉजिक**: प्रतिस्थापन मॉड्यूल के फंक्शन कॉल और तर्क प्रबंधन, जिसमें शामिल है:
   - प्लेसहोल्डर्स के इम्पोर्ट
   - प्रतिस्थापन सूचियों की लोडिंग
   - पैरेलल या सीरियल प्रतिस्थापन प्रोसेसिंग का चयन

### `esp_text_replacement_module.py` - प्रतिस्थापन मॉड्यूल

यह मॉड्यूल पाठ प्रतिस्थापन के लिए मुख्य अल्गोरिदम और फंक्शन प्रदान करता है।

#### प्रमुख घटक:

1. **एस्पेरान्तो अक्षर रूपांतरण**:
   ```python
   def replace_esperanto_chars(text, char_dict: Dict[str, str]) -> str:
       for original_char, converted_char in char_dict.items():
           text = text.replace(original_char, converted_char)
       return text
   ```
   
   विभिन्न एस्पेरान्तो अक्षर प्रारूपों के बीच परिवर्तन के लिए डिक्शनरी का उपयोग:
   - `x_to_circumflex`: cx → ĉ
   - `hat_to_circumflex`: c^ → ĉ
   - और अन्य परिवर्तन

2. **सुरक्षित प्रतिस्थापन (safe_replace)**:
   ```python
   def safe_replace(text: str, replacements: List[Tuple[str, str, str]]) -> str:
       valid_replacements = {}
       # पहले original → placeholder
       for old, new, placeholder in replacements:
           if old in text:
               text = text.replace(old, placeholder)
               valid_replacements[placeholder] = new
       # फिर placeholder → replacement
       for placeholder, new in valid_replacements.items():
           text = text.replace(placeholder, new)
       return text
   ```
   
   जटिल परिवर्तनों के लिए दो-चरण प्रतिस्थापन प्रक्रिया को लागू करता है।

3. **समग्र प्रतिस्थापन ऑर्केस्ट्रेशन**:
   ```python
   def orchestrate_comprehensive_esperanto_text_replacement(
       text, 
       placeholders_for_skipping_replacements: List[str],
       # ... अन्य पैरामीटर ...
   ) -> str:
   ```
   
   यह मुख्य फंक्शन पूरी प्रतिस्थापन प्रक्रिया को नियंत्रित करता है, % और @ विशेष प्रतीकों को संभालता है, और सभी प्रतिस्थापन चरणों को एक में एकीकृत करता है।

4. **समानांतर प्रसंस्करण (पैरेलल प्रोसेसिंग)**:
   ```python
   def parallel_process(
       text: str,
       num_processes: int,
       # ... अन्य पैरामीटर ...
   ) -> str:
   ```
   
   `multiprocessing` का उपयोग करके बड़े पाठों को समानांतर में प्रसंस्करण के लिए विभाजित करता है।

### `esp_replacement_json_make_module.py` - JSON निर्माण मॉड्यूल

यह मॉड्यूल प्रतिस्थापन JSON फाइलों के निर्माण के लिए विशेषज्ञ फंक्शन प्रदान करता है।

#### प्रमुख घटक:

1. **अक्षर चौड़ाई माप**:
   ```python
   def measure_text_width_Arial16(text, char_widths_dict: Dict[str, int]) -> int:
   ```
   
   Arial फॉन्ट का उपयोग करके पाठ की चौड़ाई (पिक्सेल में) की गणना करता है, जो रूबी फॉर्मेटिंग में महत्वपूर्ण है।

2. **आउटपुट फॉर्मेटिंग**:
   ```python
   def output_format(main_text, ruby_content, format_type, char_widths_dict):
   ```
   
   मूल पाठ और रूबी सामग्री को चयनित प्रारूप (HTML, कोष्ठक, आदि) में परिवर्तित करता है।

3. **पैरेलल बिल्ड फंक्शन**:
   ```python
   def parallel_build_pre_replacements_dict(
       E_stem_with_Part_Of_Speech_list: List[List[str]],
       replacements: List[Tuple[str, str, str]],
       num_processes: int = 4
   ) -> Dict[str, List[str]]:
   ```
   
   बड़े JSON फाइल बनाते समय कई कोर का उपयोग करके प्रतिस्थापन डिक्शनरी निर्माण को गति देता है।

### `एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ.py` - JSON जनरेटर पेज

यह फाइल Streamlit के "pages" फ़ोल्डर में होती है और कस्टम प्रतिस्थापन JSON फाइलों के निर्माण के लिए एक अलग UI प्रदान करती है।

#### प्रमुख घटक:

1. **प्रतिस्थापन सूचियों का निर्माण**:
   - CSV से एस्पेरान्तो शब्द मूल → अनुवाद/कान्जी मैपिंग आयात
   - प्राथमिकता क्रम में व्यवस्थित विभिन्न प्रतिस्थापन सूचियों का निर्माण
   - शब्द मूल विखंडन और प्रतिस्थापन नियम लागू करना

2. **अतिरिक्त प्रतिस्थापन प्रकार**:
   ```python
   verb_suffix_2l = {
       'as':'as', 'is':'is', 'os':'os', 'us':'us','at':'at','it':'it','ot':'ot',
       'ad':'ad','iĝ':'iĝ','ig':'ig','ant':'ant','int':'int','ont':'ont'
   }
   ```
   
   क्रिया प्रत्यय और अन्य विशेष एस्पेरान्तो प्रत्ययों के लिए प्रतिस्थापन नियम।

3. **जटिल प्रतिस्थापन सूची निर्माण**:
   - `replacements_final_list`: सार्वभौमिक प्रतिस्थापन के लिए मुख्य सूची
   - `replacements_list_for_2char`: दो-अक्षर शब्द मूलों के लिए विशेष सूची
   - `replacements_list_for_localized_string`: स्थानीय (@ चिह्नित) क्षेत्रों के लिए सूची

## प्रतिस्थापन अल्गोरिदम विस्तृत विश्लेषण

### सुरक्षित प्रतिस्थापन प्रक्रिया

ऐप्लिकेशन की मुख्य प्रतिस्थापन प्रक्रिया इस प्रकार कार्य करती है:

1. **पूर्व-प्रसंस्करण**:
   - एस्पेरान्तो विशेष अक्षरों को मानकीकृत करना (cx/c^ → ĉ)
   - पाठ में % से चिह्नित क्षेत्रों को प्लेसहोल्डर्स से प्रतिस्थापित करना
   - पाठ में @ से चिह्नित क्षेत्रों को पहचानना और अलग से प्रसंस्करण के लिए प्लेसहोल्डर्स से प्रतिस्थापित करना

2. **मुख्य प्रतिस्थापन**:
   - सार्वभौमिक प्रतिस्थापन सूची (`replacements_final_list`) लागू करना
   - दो-अक्षर शब्द मूल प्रतिस्थापन (`replacements_list_for_2char`) लागू करना
   - दो-अक्षर शब्द मूल प्रतिस्थापन की दूसरी पास (अतिरिक्त प्रतिस्थापन के लिए)

3. **प्लेसहोल्डर वापसी**:
   - @ क्षेत्रों के लिए प्लेसहोल्डर्स को स्थानीय रूप से प्रतिस्थापित पाठ से बदलना
   - % क्षेत्रों के लिए प्लेसहोल्डर्स को मूल अप्रतिस्थापित पाठ से बदलना

4. **पोस्ट-प्रोसेसिंग**:
   - HTML आउटपुट के लिए, पाठ को उचित HTML प्रारूप में फॉर्मेट करना
   - उपयोगकर्ता द्वारा चुने गए एस्पेरान्तो विशेष अक्षर प्रारूप (ĉ/cx/c^) लागू करना

### प्राथमिकता-आधारित प्रतिस्थापन

प्रतिस्थापन प्रक्रिया में प्राथमिकता सिस्टम महत्वपूर्ण भूमिका निभाता है:

```python
pre_replacements_dict_2[i.replace('/', '')] = [
    j[0].replace("</rt></ruby>","%%%").replace('/', '').replace("%%%","</rt></ruby>"),
    j[1],
    len(i.replace('/', ''))*10000
]
```

शब्दों को उनकी लंबाई के आधार पर प्राथमिकता दी जाती है (लंबा शब्द = उच्च प्राथमिकता)। इससे यह सुनिश्चित होता है कि छोटे शब्दों के अंदर लंबे शब्द प्रतिस्थापित न हो जाएँ।

### HTML रूबी प्रारूप का निर्माण

रूबी एनोटेशन आउटपुट के लिए, ऐप्लिकेशन पाठ और अनुवाद की सापेक्ष चौड़ाई के आधार पर स्वचालित रूप से फॉन्ट आकार समायोजित करता है:

```python
if format_type == 'HTML格式_Ruby文字_大小调整':
    width_ruby = measure_text_width_Arial16(ruby_content, char_widths_dict)
    width_main = measure_text_width_Arial16(main_text, char_widths_dict)
    ratio_1 = width_ruby / width_main
    if ratio_1 > 6:
        return f'<ruby>{main_text}<rt class="XXXS_S">{insert_br_at_third_width(ruby_content, char_widths_dict)}</rt></ruby>'
    # ... अन्य अनुपात विकल्प ...
    else:
        return f'<ruby>{main_text}<rt class="XXL_L">{ruby_content}</rt></ruby>'
```

यह तकनीक रूबी (अनुवाद) के लिए फॉन्ट का आकार स्वचालित रूप से समायोजित करती है जिससे यह मूल पाठ के सापेक्ष सुंदर और पठनीय दिखे।

## समानांतर प्रोसेसिंग कार्यान्वयन

बड़े पाठों के प्रसंस्करण की दक्षता बढ़ाने के लिए, ऐप्लिकेशन Python के `multiprocessing` मॉड्यूल का उपयोग करता है:

```python
def parallel_process(
    text: str,
    num_processes: int,
    # ... अन्य पैरामीटर ...
) -> str:
    # Streamlit में multiprocessing के लिए, 'spawn' मोड सेट करें
    # multiprocessing.set_start_method("spawn") - main.py में
    
    # पाठ को पंक्तियों में विभाजित करें
    lines = re.findall(r'.*?\n|.+$', text)
    
    # प्रत्येक प्रोसेस को पंक्तियों का एक हिस्सा दें
    chunks = [lines[i:i+n] for i in range(0, len(lines), n)]
    
    # समानांतर में प्रत्येक चंक का प्रसंस्करण करें
    with multiprocessing.Pool(processes=num_processes) as pool:
        results = pool.starmap(process_segment, [...])
        
    # परिणामों को जोड़ें
    return ''.join(results)
```

यह कार्यान्वयन:
1. पाठ को लाइनों में विभाजित करता है
2. लाइनों को प्रोसेसों की संख्या के अनुसार चंक्स में विभाजित करता है
3. प्रत्येक चंक `process_segment()` फंक्शन को समानांतर में पास करता है
4. अंत में सभी परिणामों को जोड़ता है

यह विधि बड़े पाठों के प्रसंस्करण समय को महत्वपूर्ण रूप से कम कर सकती है, विशेष रूप से बहु-कोर सिस्टम पर।

## JSON जनरेटर पेज विश्लेषण

JSON जनरेटर पेज (एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ.py) प्रतिस्थापन JSON फाइलों के निर्माण के लिए एक जटिल तंत्र प्रदान करता है।

### मुख्य प्रक्रिया चरण:

1. **CSV डेटा आयात**:
   ```python
   CSV_data_imported = pd.read_csv(csv_buffer, encoding="utf-8", usecols=[0, 1])
   ```
   
   CSV से एस्पेरान्तो शब्द मूल और उनके अनुवाद/कान्जी प्रतिस्थापन की जोड़ी को आयात करता है।

2. **अस्थायी प्रतिस्थापन सूची निर्माण**:
   ```python
   temporary_replacements_dict = {}
   # ... CSV डेटा प्रोसेसिंग ...
   temporary_replacements_list_1 = []
   for old, new in temporary_replacements_dict.items():
       temporary_replacements_list_1.append((old, new[0], new[1]))
   ```
   
   CSV डेटा से प्रारंभिक प्रतिस्थापन सूची बनाता है।

3. **प्राथमिकता-आधारित सॉर्टिंग**:
   ```python
   temporary_replacements_list_2 = sorted(temporary_replacements_list_1, key=lambda x: x[2], reverse=True)
   ```
   
   प्रतिस्थापन सूची को लंबाई (प्राथमिकता) के अनुसार घटते क्रम में सॉर्ट करता है।

4. **शब्द मूल विखंडन और विस्तार**:
   ```python
   pre_replacements_dict_1 = {}
   for i, j in enumerate(E_stem_with_Part_Of_Speech_list):
       # ... word stemming and processing ...
   ```
   
   एस्पेरान्तो शब्दों का विश्लेषण करता है और विभिन्न प्रतिस्थापन पैटर्न के लिए उन्हें अलग-अलग करता है।

5. **अतिरिक्त प्रतिस्थापन जनरेशन**:
   ```python
   for i,j in pre_replacements_dict_1.items():
       # ... verbForm और special suffix handling ...
   ```
   
   क्रिया रूपों, प्रत्ययों, और विशेष मामलों के लिए अतिरिक्त प्रतिस्थापन उत्पन्न करता है।

6. **विशेष शब्द मूल प्रोसेसिंग**:
   ```python
   # AN, ON, verb_suffix जैसे विशेष केस
   for an in AN:
       # ... AN प्रतिस्थापन जनरेशन ...
   ```
   
   "an", "on" जैसे विशेष प्रत्ययों और शब्द मूलों के लिए अतिरिक्त प्रतिस्थापन बनाता है।

7. **कस्टम सेटिंग्स एप्लिकेशन**:
   ```python
   for i in custom_stemming_setting_list:
       # ... apply custom stemming rules ...
   ```
   
   उपयोगकर्ता-परिभाषित शब्द विखंडन नियमों और प्रतिस्थापन वरीयताओं को लागू करता है।

8. **अंतिम JSON संयोजन**:
   ```python
   combined_data = {}
   combined_data["全域替换用のリスト..."] = replacements_final_list
   combined_data["二文字词根替换用のリスト..."] = replacements_list_for_2char
   combined_data["局部文字替换用のリスト..."] = replacements_list_for_localized_string
   ```
   
   तीनों प्रतिस्थापन सूचियों को एक JSON संरचना में संयोजित करता है।

इस प्रक्रिया का परिणाम एक जटिल JSON फाइल है जिसे मुख्य ऐप्लिकेशन द्वारा प्रतिस्थापन नियमों के रूप में उपयोग किया जा सकता है।

   - विभिन्न रूबी क्लास साइज़ स्केल को समायोजित करें
