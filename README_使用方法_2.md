# एस्पेरांतो पाठ कान्जी/हिंदी प्रतिस्थापन एवं रूबी अनोटेशन टूल - उपयोगकर्ता निर्देशिका

मैंने आपके द्वारा प्रदान किए गए चारों Python कोड फ़ाइलों का विश्लेषण करके एक विस्तृत हिंदी उपयोगकर्ता निर्देशिका तैयार की है। यह निर्देशिका हिंदी भाषी उपयोगकर्ताओं को एस्पेरांतो पाठ प्रतिस्थापन और रूबी अनोटेशन ऐप का उपयोग करने में मदद करेगी।

निर्देशिका में निम्नलिखित प्रमुख अनुभाग शामिल हैं:

1. **परिचय**: ऐप के मुख्य उद्देश्य और कार्यों का परिचय
2. **मुख्य पृष्ठ का उपयोग**: JSON फ़ाइल चयन, उन्नत सेटिंग्स, आउटपुट फॉर्मेट और अन्य विकल्पों का विवरण
3. **JSON फ़ाइल जनरेटर का उपयोग**: कस्टम प्रतिस्थापन नियम बनाने के लिए विस्तृत निर्देश
4. **नमूना फ़ाइलें**: उपलब्ध नमूना फ़ाइलों का विवरण
5. **विशेष विशेषताएँ और सुझाव**: बेहतर परिणामों के लिए उपयोगी टिप्स
6. **अन्य भाषा संस्करण**: अन्य भाषाओं में उपलब्ध संस्करणों के बारे में जानकारी
7. **तकनीकी नोट्स**: कुछ महत्वपूर्ण तकनीकी विवरण

इस निर्देशिका से हिंदी भाषी उपयोगकर्ता एस्पेरांतो पाठ को चीनी अक्षरों या हिंदी अनुवादों में प्रतिस्थापित करने और उन्हें सुंदर रूबी अनोटेशन के साथ प्रस्तुत करने में सक्षम होंगे। मैंने विशेष रूप से ध्यान दिया है कि सभी तकनीकी अवधारणाओं को सरल हिंदी में समझाया जाए, और प्रत्येक विकल्प और सुविधा का उद्देश्य स्पष्ट किया जाए।

क्या आप चाहेंगे कि मैं निर्देशिका के किसी विशेष भाग पर अधिक विस्तार से जानकारी प्रदान करूं?



# एस्पेरांतो पाठ कान्जी/हिंदी प्रतिस्थापन एवं रूबी अनोटेशन टूल - उपयोगकर्ता निर्देशिका

## परिचय

यह ऐप एस्पेरांतो पाठ को कान्जी (चीनी अक्षर) या हिंदी अनुवाद में प्रतिस्थापित करने और उनमें रूबी अनोटेशन जोड़ने के लिए बनाया गया है। यह टूल मुख्य रूप से निम्नलिखित कार्य करता है:

1. **प्रतिस्थापन**: एस्पेरांतो शब्दों को चीनी अक्षरों या हिंदी अनुवादों से प्रतिस्थापित करना
2. **रूबी अनोटेशन**: प्रतिस्थापित शब्दों के ऊपर/नीचे मूल एस्पेरांतो शब्द दिखाना
3. **विभिन्न प्रारूप**: HTML, कोष्ठक प्रारूप, या सरल प्रतिस्थापन में आउटपुट प्रदान करना
4. **अनुकूलन**: अपने स्वयं के प्रतिस्थापन नियम बनाने की क्षमता

इस ऐप के मुख्य भाग दो हैं:
- **मुख्य पृष्ठ**: जहां आप एस्पेरांतो पाठ प्रतिस्थापित कर सकते हैं
- **JSON फ़ाइल जनरेटर पृष्ठ**: जहां आप अपने प्रतिस्थापन नियम बना सकते हैं

## मुख्य पृष्ठ का उपयोग

### 1. JSON फ़ाइल के साथ कार्य करना

सबसे पहले, आपको प्रतिस्थापन नियमों वाली JSON फ़ाइल चुननी होगी:

- **डिफ़ॉल्ट JSON का उपयोग करें**: उपलब्ध प्रतिस्थापन नियमों का उपयोग करता है
- **फ़ाइल अपलोड करें**: अपनी खुद की JSON फ़ाइल अपलोड करें (यदि आपने पहले बनाई है)

"नमूना JSON फ़ाइल डाउनलोड करें" विकल्प का उपयोग करके डिफ़ॉल्ट JSON फ़ाइल को भी डाउनलोड कर सकते हैं।

### 2. उन्नत सेटिंग्स (पैरेलल प्रोसेसिंग)

बड़े पाठों के लिए, एक साथ चलने वाले प्रोसेस की संख्या सेट करके प्रतिस्थापन प्रक्रिया को गति दे सकते हैं:

- **पैरेलल प्रोसेसिंग का उपयोग करें**: (चेकबॉक्स) बड़े पाठों के लिए अधिक प्रोसेसर का उपयोग करना
- **समकालिक प्रोसेस की संख्या**: 2 से 4 तक प्रोसेस का चयन करें (अधिक प्रोसेस से अधिक गति)

### 3. आउटपुट फॉर्मेट चुनें

आप विभिन्न प्रकार के आउटपुट फॉर्मेट चुन सकते हैं:

- **HTML फॉर्मेट, रुबी एनोटेशन और आकार समायोजन के साथ**: मूल शब्द के ऊपर रूबी अनोटेशन जोड़ता है, आकार स्वचालित रूप से समायोजित होता है
- **HTML फॉर्मेट, रुबी एनोटेशन, आकार समायोजन और कान्जी प्रतिस्थापन**: कान्जी/हिंदी को मुख्य शब्द के रूप में दिखाता है, एस्पेरांतो को रूबी में
- **HTML फॉर्मेट**: साधारण HTML रूबी टैग का उपयोग करता है, आकार समायोजन के बिना
- **HTML फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: HTML में एस्पेरांतो को रूबी में और कान्जी/हिंदी को मुख्य में दिखाता है
- **कोष्ठकों वाला फॉर्मेट**: मूल शब्द के बाद कोष्ठक में अनुवाद दिखाता है, जैसे: Esperanto(एस्पेरांतो)
- **कोष्ठकों वाला फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: अनुवाद के बाद कोष्ठक में मूल एस्पेरांतो शब्द, जैसे: एस्पेरांतो(Esperanto)
- **केवल बदला हुआ पाठ रखें**: केवल प्रतिस्थापित शब्द दिखाता है, मूल एस्पेरांतो शब्द नहीं

उस फॉर्मेट का चयन करें जो आपके JSON फ़ाइल में परिभाषित है।

### 4. इनपुट पाठ का स्रोत

एस्पेरांतो पाठ प्रदान करने के दो तरीके हैं:

- **मैन्युअल इनपुट**: टेक्स्ट बॉक्स में सीधे एस्पेरांतो पाठ टाइप करें
- **फ़ाइल अपलोड**: UTF-8 एन्कोडिंग में एक टेक्स्ट फ़ाइल (.txt, .csv, या .md) अपलोड करें

### 5. विशेष मार्करों का उपयोग

आप पाठ के कुछ हिस्सों को विशेष मार्करों से घेर सकते हैं:

- **% मार्कर**: `%<50 अक्षरों तक का पाठ>%` - इस तरह से घिरा हुआ पाठ प्रतिस्थापित नहीं किया जाएगा
- **@ मार्कर**: `@<18 अक्षरों तक का पाठ>@` - इस तरह से घिरा हुआ पाठ केवल आंशिक/स्थानीय तौर पर प्रतिस्थापित होगा

### 6. एस्पेरांतो विशेष अक्षरों का प्रदर्शन

एस्पेरांतो के विशेष अक्षरों (ĉ, ĝ, ĥ, ĵ, ŝ, ŭ) को प्रदर्शित करने के तीन तरीके चुन सकते हैं:

- **अक्षर के ऊपर संकेत**: ĉ → c + ˆ (अक्षर के ऊपर कैरेट चिह्न)
- **x फॉर्मेट**: ĉ → cx (अक्षर के बाद 'x')
- **^ फॉर्मेट**: ĉ → c^ (अक्षर के बाद '^' चिह्न)

### 7. प्रतिस्थापन प्रक्रिया

सभी सेटिंग्स कॉन्फ़िगर करने के बाद:

1. **सबमिट** बटन दबाएं
2. ऐप आपके एस्पेरांतो पाठ को प्रतिस्थापित करेगा
3. आउटपुट HTML पूर्वावलोकन या टेक्स्ट के रूप में दिखाया जाएगा
4. "परिणाम डाउनलोड करें" बटन दबाकर प्रतिस्थापित पाठ को HTML फ़ाइल के रूप में डाउनलोड कर सकते हैं

बहुत बड़े पाठ के लिए (250+ पंक्तियां), सिस्टम केवल आंशिक पूर्वावलोकन दिखाएगा, लेकिन डाउनलोड फ़ाइल में पूरा पाठ होगा।

## JSON फ़ाइल जनरेटर का उपयोग

यदि आप अपने स्वयं के प्रतिस्थापन नियम बनाना चाहते हैं, तो आप JSON फ़ाइल जनरेटर पृष्ठ का उपयोग कर सकते हैं (दूसरा टैब)।

### 1. CSV फ़ाइल की तैयारी

सबसे पहले, एस्पेरांतो शब्दमूल और उनके अनुवादों वाली CSV फ़ाइल चुनें:

- **CSV अपलोड करें**: अपनी स्वयं की फ़ाइल अपलोड करें
- **डिफ़ॉल्ट फ़ाइल प्रयोग करें**: पहले से उपलब्ध हिंदी अनुवाद CSV का उपयोग करें

CSV फ़ाइल में प्रत्येक पंक्ति में एक एस्पेरांतो शब्दमूल और उसका अनुवाद होना चाहिए।

### 2. JSON फ़ाइल तैयारी

अब, एस्पेरांतो शब्दमूल विखंडन और प्रतिस्थापन सेटिंग्स के लिए JSON फ़ाइलें चुनें:

- **शब्दमूल विखंडन नियम वाली JSON**: यह बताता है कि एस्पेरांतो शब्दों को कैसे विखंडित करना है
- **प्रतिस्थापित होने वाले टेक्स्ट की JSON**: विशेष प्रतिस्थापन नियम निर्धारित करता है

दोनों के लिए, आप अपनी फ़ाइल अपलोड कर सकते हैं या डिफ़ॉल्ट फ़ाइल का उपयोग कर सकते हैं।

### 3. आउटपुट प्रारूप चुनें

आप उसी प्रकार के आउटपुट फॉर्मेट चुन सकते हैं जो मुख्य पृष्ठ पर उपलब्ध हैं।

### 4. JSON फ़ाइल जनरेट करना

बड़े डेटासेट के लिए पैरेलल प्रोसेसिंग को सक्षम करके प्रक्रिया को तेज़ कर सकते हैं:

- **पैरेलल प्रोसेसिंग का प्रयोग करें**: चेकबॉक्स सक्षम करें
- **एक साथ चलने वाले प्रोसेसों की संख्या**: प्रोसेसर की संख्या चुनें (2-6)

"प्रत्यस्थापन JSON फ़ाइल तैयार करें" बटन दबाकर, सिस्टम:

1. आपके इनपुट डेटा को प्रोसेस करेगा
2. तीन प्रकार के प्रतिस्थापन लिस्ट बनाएगा:
   - पूरे पाठ के लिए प्रतिस्थापन
   - दो-अक्षर शब्दमूल के लिए विशेष प्रतिस्थापन
   - स्थानीय/आंशिक प्रतिस्थापन (@...@ मार्कर के भीतर)
3. अंतिम JSON फ़ाइल डाउनलोड करने का विकल्प देगा

इस फ़ाइल को फिर मुख्य पृष्ठ पर अपलोड करके अपने कस्टम प्रतिस्थापन नियमों का उपयोग कर सकते हैं।

## नमूना फ़ाइलें

निर्देशिका में कई नमूना फ़ाइलें शामिल हैं जिन्हें डाउनलोड किया जा सकता है:

- **नमूना CSV फ़ाइलें**: एस्पेरांतो शब्दमूल-हिंदी/चीनी अनुवाद
- **नमूना JSON फ़ाइलें**: शब्द विखंडन नियम और प्रतिस्थापन सेटिंग्स
- **नमूना Excel फ़ाइलें**: 14 भाषाओं में एस्पेरांतो शब्दमूल और रूबी टिप्पणियाँ

इन फ़ाइलों का उपयोग अपने स्वयं के प्रतिस्थापन नियम बनाने के लिए संदर्भ के रूप में किया जा सकता है।

## विशेष विशेषताएँ और सुझाव

### प्रतिस्थापन को नियंत्रित करना

- बड़े पाठों को हिस्सों में प्रतिस्थापित करने के लिए पैरेलल प्रोसेसिंग का उपयोग करें
- `%...%` मार्करों का उपयोग करके विशेष शब्दों या वाक्यांशों को प्रतिस्थापन से बचाएं
- `@...@` मार्करों का उपयोग करके पाठ के कुछ हिस्सों में अलग प्रतिस्थापन नियम लागू करें

### उच्च गुणवत्ता वाले आउटपुट के लिए

- HTML रूबी फॉर्मेट का उपयोग करें जहां आकार समायोजन हो, खासकर जब एस्पेरांतो शब्द और उनके अनुवाद में लंबाई का अंतर हो
- पूर्वावलोकन टैब का उपयोग करके प्रतिस्थापन की जाँच करें और HTML कोड टैब से आवश्यकतानुसार समायोजित करें
- HTML आउटपुट को किसी भी वेब ब्राउज़र में खोला जा सकता है और यह मोबाइल डिवाइसों पर भी अच्छी तरह से प्रदर्शित होता है

### सुझाव

- हमेशा UTF-8 एन्कोडिंग का उपयोग करें अपनी CSV और टेक्स्ट फ़ाइलों के लिए
- बड़े प्रतिस्थापन के लिए, विशेष प्रतिस्थापन पैटर्न के साथ पहले एक छोटे पाठ पर परीक्षण करें
- कस्टम प्रतिस्थापन सेटिंग्स वाली JSON फ़ाइलों को डाउनलोड करके बाद के उपयोग के लिए बचाएं

## अन्य भाषा संस्करण

इस ऐप के अन्य भाषा संस्करण भी उपलब्ध हैं, जिन्हें पृष्ठ के निचले भाग में लिंक से एक्सेस किया जा सकता है। अंग्रेजी, जापानी, चीनी, कोरियाई, रूसी, स्पेनिश, इतालियन, फ्रेंच, जर्मन, अरबी, पोलिश, वियतनामी और इंडोनेशियन सहित 14 भाषाओं में संस्करण उपलब्ध हैं।

## तकनीकी नोट्स

- ऐप एस्पेरांतो के विशेष अक्षरों के विभिन्न प्रतिनिधित्वों (ĉ, cx, c^) को पहचान सकता है
- HTML रूबी अनोटेशन में सभी प्रमुख ब्राउज़रों में अच्छी तरह से दिखाई देने के लिए CSS शामिल है
- कस्टम रूबी क्लास के माध्यम से रूबी टेक्स्ट का आकार स्वचालित रूप से समायोजित होता है
- JSON फ़ाइलों में तीन प्रकार के प्रतिस्थापन नियम होते हैं:
  - `全域替换用のリスト` (वैश्विक प्रतिस्थापन के लिए लिस्ट)
  - `局部文字替换用のリスト` (स्थानीय प्रतिस्थापन के लिए लिस्ट)
  - `二文字词根替换用のリスト` (दो-अक्षर शब्दमूल प्रतिस्थापन के लिए लिस्ट)
