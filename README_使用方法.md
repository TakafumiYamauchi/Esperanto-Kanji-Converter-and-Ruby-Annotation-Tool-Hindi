## परिचय

एस्पेरांतो पाठ कान्जी/HTML रूबी प्रतिस्थापन उपकरण एक वेब आधारित एप्लिकेशन है जिसे स्ट्रीमलिट का उपयोग करके विकसित किया गया है। यह एप्लिकेशन एस्पेरांतो भाषा के पाठ को प्रसंस्करित करके निम्नलिखित कार्य करता है:

1. एस्पेरांतो शब्दों को चीनी कान्जी अक्षरों से प्रतिस्थापित करना
2. एस्पेरांतो शब्दों के ऊपर रूबी अनोटेशन (HTML में) जोड़ना
3. विभिन्न प्रारूपों में आउटपुट प्रदान करना (HTML, कोष्ठक प्रारूप, आदि)

इस एप्लिकेशन का मुख्य उद्देश्य एस्पेरांतो सीखने वालों को सहायता प्रदान करना है, जिससे वे एस्पेरांतो शब्दों के अर्थ और उच्चारण को आसानी से समझ सकें।

## मुख्य एप्लिकेशन (main.py)

जब आप एप्लिकेशन को स्ट्रीमलिट क्लाउड पर खोलते हैं, तो आपको मुख्य इंटरफ़ेस दिखाई देगा। यह निम्न खंडों में विभाजित है:

### JSON फ़ाइल का उपयोग

सबसे पहले, आपको प्रतिस्थापन नियमों वाली JSON फ़ाइल का चयन करना होगा:

1. **डिफ़ॉल्ट JSON का उपयोग करें**: एप्लिकेशन में पहले से उपलब्ध प्रतिस्थापन नियमों का उपयोग करने के लिए
2. **फ़ाइल अपलोड करें**: अपने स्वयं के कस्टम प्रतिस्थापन नियमों का उपयोग करने के लिए

इसके नीचे एक "नमूना JSON फ़ाइल डाउनलोड करें" विकल्प है, जिससे आप संदर्भ के लिए डिफ़ॉल्ट JSON फ़ाइल डाउनलोड कर सकते हैं।

### उन्नत सेटिंग्स

"उन्नत सेटिंग्स (पैरलल प्रोसेसिंग)" विभाग में, आप निम्न विकल्पों को कॉन्फ़िगर कर सकते हैं:

1. **पैरलल प्रोसेसिंग का उपयोग करें**: बड़े पाठ के लिए प्रसंस्करण को तेज करने के लिए समानांतर प्रसंस्करण सक्षम करें
2. **समकालिक प्रोसेस की संख्या**: एक साथ चलने वाले प्रोसेसों की संख्या (2 से 4 तक)

पैरलल प्रोसेसिंग का उपयोग बड़े पाठ (10,000+ शब्द) के लिए अनुशंसित है, क्योंकि यह प्रसंस्करण समय को महत्वपूर्ण रूप से कम कर सकता है।

### आउटपुट फॉर्मेट का चयन

आप निम्नलिखित आउटपुट फॉर्मेट में से एक का चयन कर सकते हैं:

1. **HTML फॉर्मेट, रुबी एनोटेशन और आकार समायोजन के साथ**: एस्पेरांतो शब्दों के ऊपर छोटे फॉन्ट में अर्थ दिखाता है, आकार स्वचालित रूप से समायोजित होता है
2. **HTML फॉर्मेट, रुबी एनोटेशन, आकार समायोजन और कान्जी प्रतिस्थापन**: एस्पेरांतो शब्दों को कान्जी से बदल देता है और मूल एस्पेरांतो शब्द रुबी के रूप में दिखते हैं
3. **HTML फॉर्मेट**: बिना आकार समायोजन के सरल HTML रुबी
4. **HTML फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: बिना आकार समायोजन के कान्जी प्रतिस्थापन
5. **कोष्ठकों वाला फॉर्मेट**: एस्पेरांतो शब्द के बाद कोष्ठक में अर्थ दिखाता है
6. **कोष्ठकों वाला फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: कान्जी के बाद कोष्ठक में एस्पेरांतो शब्द दिखाता है
7. **केवल बदला हुआ पाठ रखें (सरल प्रतिस्थापन)**: केवल प्रतिस्थापित पाठ दिखाता है, मूल एस्पेरांतो को छोड़ देता है

महत्वपूर्ण: आपका चयनित फॉर्मेट आपके प्रतिस्थापन JSON में परिभाषित फॉर्मेट से मेल खाना चाहिए।

### इनपुट पाठ स्रोत

आप दो तरीकों से एस्पेरांतो पाठ प्रदान कर सकते हैं:

1. **मैन्युअल इनपुट**: टेक्स्ट एरिया में सीधे एस्पेरांतो पाठ टाइप करें
2. **फ़ाइल अपलोड**: UTF-8 एन्कोडिंग के साथ .txt, .csv, या .md फ़ाइल अपलोड करें

### एस्पेरांतो पाठ प्रसंस्करण

पाठ प्रदान करने के बाद, आपको एस्पेरांतो के विशेष अक्षरों (ĉ, ĝ, ĥ, ĵ, ŝ, ŭ) को दिखाने का तरीका चुनना होगा:

1. **अक्षर के ऊपर संकेत (ĉ → c + ˆ)**: मानक एस्पेरांतो उच्चारण चिह्नों का उपयोग करता है
2. **x फॉर्मेट (ĉ → cx)**: एस्पेरांतो अक्षरों को उनके ASCII समकक्षों के बाद 'x' जोड़कर दर्शाता है
3. **^ फॉर्मेट (ĉ → c^)**: एस्पेरांतो अक्षरों को उनके ASCII समकक्षों के बाद '^' जोड़कर दर्शाता है

अपनी पसंद का चयन करने के बाद, "सबमिट" बटन पर क्लिक करें। एप्लिकेशन आपके पाठ को प्रसंस्करित करेगा और परिणाम दिखाएगा।

### परिणाम देखना और डाउनलोड करना

प्रसंस्करण पूरा होने के बाद, आप परिणाम देख सकते हैं और इसे डाउनलोड कर सकते हैं:

- **HTML आउटपुट** के लिए, दो टैब दिखाई देंगे: "HTML पूर्वावलोकन" और "परिणाम (HTML कोड)"
- **गैर-HTML आउटपुट** के लिए, एक "परिणामी पाठ" टैब दिखाई देगा

परिणाम को डाउनलोड करने के लिए "परिणाम डाउनलोड करें" बटन पर क्लिक करें। फ़ाइल "प्रतिस्थापन_परिणाम.html" के रूप में सहेजी जाएगी।

## JSON फ़ाइल जनरेटर पेज

एप्लिकेशन के साइडबार मेनू में "एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ" पर क्लिक करके आप अपनी खुद की प्रतिस्थापन JSON फ़ाइल बना सकते हैं।

इस पेज का उपयोग मुख्य एप्लिकेशन में उपयोग किए जाने वाले प्रतिस्थापन नियमों को अनुकूलित करने के लिए किया जाता है। यह पेज तीन मुख्य चरणों में विभाजित है:

### CSV फ़ाइल तैयारी

पहले चरण में, आपको एस्पेरांतो शब्दमूल और उनके अनुवाद/कान्जी प्रतिस्थापन वाली CSV फ़ाइल चुननी होगी:

1. **CSV अपलोड करें**: अपनी स्वयं की CSV फ़ाइल अपलोड करें
2. **डिफ़ॉल्ट फ़ाइल प्रयोग करें**: पहले से उपलब्ध डिफ़ॉल्ट CSV फ़ाइल का उपयोग करें

आप इस पेज पर उपलब्ध "नमूना फ़ाइलों की सूची" विस्तार अनुभाग से विभिन्न नमूना CSV फ़ाइलें डाउनलोड कर सकते हैं।

CSV फ़ाइल का प्रारूप सरल होना चाहिए: पहला कॉलम एस्पेरांतो शब्दमूल, दूसरा कॉलम हिंदी या कान्जी अनुवाद।

### JSON फ़ाइल तैयारी

दूसरे चरण में, आपको शब्दमूल विखंडन नियम और प्रतिस्थापित टेक्स्ट सेटिंग्स के लिए JSON फ़ाइलें चुननी होंगी:

1. **शब्दमूल विखंडन नियम वाली JSON**:
   - **अपलोड करें**: अपनी स्वयं की JSON फ़ाइल अपलोड करें
   - **डिफ़ॉल्ट फ़ाइल**: पहले से उपलब्ध डिफ़ॉल्ट JSON फ़ाइल का उपयोग करें

2. **प्रतिस्थापित होने वाले टेक्स्ट की JSON**:
   - **अपलोड करें**: अपनी स्वयं की JSON फ़ाइल अपलोड करें
   - **डिफ़ॉल्ट फ़ाइल**: पहले से उपलब्ध डिफ़ॉल्ट JSON फ़ाइल का उपयोग करें

ये JSON फ़ाइलें निर्धारित करती हैं कि एस्पेरांतो शब्दों को कैसे विखंडित किया जाए (उदाहरण के लिए, पूर्वसर्ग, प्रत्यय, और मूल शब्द पहचानना) और प्रत्येक शब्द या शब्दांश को किस प्रकार प्रतिस्थापित किया जाए।

### JSON फ़ाइल जनरेट करना

तीसरे और अंतिम चरण में, आप वैकल्पिक रूप से पैरलल प्रोसेसिंग सेटिंग्स कॉन्फ़िगर कर सकते हैं और फिर "प्रत्यस्थापन JSON फ़ाइल तैयार करें" बटन पर क्लिक कर सकते हैं।

प्रोसेसिंग पूरी होने के बाद, आप "अंतिम प्रतिस्थापन लिस्ट (3 संयुक्त JSON) डाउनलोड" बटन का उपयोग करके संयुक्त JSON फ़ाइल डाउनलोड कर सकते हैं। यह जनरेट की गई फ़ाइल मुख्य एप्लिकेशन पेज पर प्रतिस्थापन के लिए उपयोग की जा सकती है।

## विशेष प्रतिस्थापन नियम

एप्लिकेशन में दो विशेष प्रतिस्थापन नियम हैं जो आपको पाठ के विशिष्ट हिस्सों को संभालने में मदद कर सकते हैं:

### प्रतिस्थापन से बचाना (%)

यदि आप पाठ के किसी हिस्से को प्रतिस्थापन से बचाना चाहते हैं, तो उसे `%` चिह्न से घेर दें। उदाहरण के लिए:

```
%Mi estas komencanto.% Mi lernas Esperanton.
```

इस उदाहरण में, "Mi estas komencanto." वाक्य प्रतिस्थापन से नहीं बदलेगा, जबकि "Mi lernas Esperanton." प्रतिस्थापित हो जाएगा।

सीमा: प्रत्येक `%...%` ब्लॉक 50 अक्षरों तक सीमित है।

### स्थानीय प्रतिस्थापन (@)

यदि आप पाठ के किसी हिस्से के लिए विशेष/स्थानीय प्रतिस्थापन चाहते हैं, तो उसे `@` चिह्न से घेर दें। उदाहरण के लिए:

```
@La suno@ brilas en la cielo.
```

इस उदाहरण में, "@La suno@" विशेष नियमों के अनुसार प्रतिस्थापित होगा (यदि परिभाषित हो), जबकि वाक्य का बाकी हिस्सा सामान्य प्रतिस्थापन नियमों का पालन करेगा।

सीमा: प्रत्येक `@...@` ब्लॉक 18 अक्षरों तक सीमित है।

## उपयोग के उदाहरण

### उदाहरण 1: सरल HTML रूबी एनोटेशन

1. आउटपुट फॉर्मेट: "HTML फॉर्मेट"
2. एस्पेरांतो पाठ:
   ```
   La rapida ruĝa vulpo saltas super la pigra hundo.
   ```
3. परिणाम: एस्पेरांतो शब्दों के ऊपर उनके अनुवाद के साथ HTML रूबी एनोटेशन।

### उदाहरण 2: कान्जी प्रतिस्थापन और आकार समायोजन के साथ HTML

1. आउटपुट फॉर्मेट: "HTML फॉर्मेट, रुबी एनोटेशन, आकार समायोजन और कान्जी प्रतिस्थापन"
2. एस्पेरांतो पाठ:
   ```
   Esperanto estas internacia lingvo kreita de L. L. Zamenhof.
   ```
3. परिणाम: एस्पेरांतो शब्दों के बजाय कान्जी/हिंदी अक्षर, जिनके ऊपर मूल एस्पेरांतो शब्द रूबी के रूप में दिखते हैं, आकार स्वचालित रूप से समायोजित होता है।

### उदाहरण 3: कोष्ठक फॉर्मेट

1. आउटपुट फॉर्मेट: "कोष्ठकों वाला फॉर्मेट"
2. एस्पेरांतो पाठ:
   ```
   Mi amas lerni novajn lingvojn.
   ```
3. परिणाम: एस्पेरांतो शब्द के बाद कोष्ठक में अनुवाद, जैसे: "Mi(मैं) amas(प्यार करता हूँ) lerni(सीखना) novajn(नए) lingvojn(भाषाएँ)."

## अक्सर पूछे जाने वाले प्रश्न

### मेरे पाठ में एस्पेरांतो के विशेष अक्षर (ĉ, ĝ, आदि) नहीं हैं। क्या यह एप्लिकेशन काम करेगा?

हां, एप्लिकेशन एस्पेरांतो के विशेष अक्षरों को स्वचालित रूप से पहचान लेगा, चाहे वे "x-system" (cx, gx, आदि) या "hat-system" (c^, g^, आदि) में हों।

### क्या मैं अपनी प्रतिस्थापन फ़ाइल बना सकता हूं?

हां, "एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ" पेज का उपयोग करके आप अपनी कस्टम प्रतिस्थापन JSON फ़ाइल बना सकते हैं। आप नमूना फ़ाइलों को संदर्भ के रूप में उपयोग कर सकते हैं।

### क्या मैं बड़े पाठ की प्रक्रिया कर सकता हूं?

हां, बड़े पाठ (10,000+ शब्द) के लिए "पैरलल प्रोसेसिंग का उपयोग करें" सेटिंग सक्षम करें। यह प्रसंस्करण को तेज करेगा। बहुत बड़े पाठ के लिए, पहले उसे छोटे खंडों में विभाजित करके प्रक्रिया करना अधिक प्रभावी हो सकता है।

### एप्लिकेशन HTML आउटपुट को कैसे फॉर्मेट करता है?

HTML फॉर्मेट के लिए, एप्लिकेशन मानक HTML `<ruby>` टैग का उपयोग करता है। "आकार समायोजन" विकल्प के साथ, यह अनुवाद/रूबी पाठ के आकार को स्वचालित रूप से समायोजित करता है, जिससे यह पढ़ने में आसान हो जाता है।

### "रिप्लेसमेंट JSON" फ़ाइल में क्या होता है?

रिप्लेसमेंट JSON फ़ाइल तीन प्रकार के प्रतिस्थापन नियमों को संग्रहीत करती है:
1. पूर्ण पाठ प्रतिस्थापन के लिए नियम
2. दो-अक्षर शब्दमूल प्रतिस्थापन के लिए विशेष नियम
3. स्थानीय प्रतिस्थापन (@...@) के लिए नियम

## समस्या निवारण

### समस्या: प्रतिस्थापन नहीं हो रहा है या अपेक्षित परिणाम नहीं मिल रहे हैं

समाधान:
1. जांचें कि आपने सही आउटपुट फॉर्मेट चुना है जो आपके प्रतिस्थापन JSON से मेल खाता है
2. सुनिश्चित करें कि एस्पेरांतो पाठ सही है और किसी फॉर्मेटिंग या एन्कोडिंग समस्या से ग्रस्त नहीं है
3. अपनी JSON फ़ाइल की जांच करें कि वह वैध है और आवश्यक प्रतिस्थापन नियम शामिल हैं

### समस्या: पैरलल प्रोसेसिंग त्रुटि

समाधान:
1. "पैरलल प्रोसेसिंग का उपयोग करें" विकल्प को अक्षम करें और फिर से प्रयास करें
2. प्रोसेसिंग की संख्या को कम करें (2 पर सेट करें)
3. अगर समस्या बनी रहती है, तो पाठ को छोटे खंडों में विभाजित करें और प्रत्येक खंड को अलग-अलग प्रोसेस करें

### समस्या: HTML आउटपुट सही प्रदर्शित नहीं होता है

समाधान:
1. "परिणाम (HTML कोड)" टैब में HTML कोड की जांच करें
2. कोड को अपने स्थानीय HTML फ़ाइल में कॉपी करें और ब्राउज़र में खोलें
3. सुनिश्चित करें कि आपका ब्राउज़र HTML रूबी टैग का समर्थन करता है

### समस्या: CSV फ़ाइल अपलोड नहीं हो रही है

समाधान:
1. CSV फ़ाइल के रूप का परीक्षण करें (पहला कॉलम: एस्पेरांतो शब्दमूल, दूसरा कॉलम: अनुवाद/कान्जी)
2. सुनिश्चित करें कि फ़ाइल UTF-8 एन्कोडिंग में है
3. CSV फ़ाइल से किसी भी विशेष वर्ण (जैसे BOM मार्कर) को हटाकर अपलोड करके देखें

## अन्य भाषा संस्करण

यह एप्लिकेशन कई भाषाओं में उपलब्ध है। आप मुख्य एप्लिकेशन पेज के नीचे "Ligilo-oj(URL-oj)" अनुभाग से अन्य भाषा संस्करणों तक पहुंच सकते हैं। उपलब्ध भाषाएँ हैं:

- एस्पेरांतो (Esperanta versio)
- अंग्रेज़ी (English version)
- जापानी (日本語版)
- चीनी (中文版)
- कोरियाई (한국어 버전)
- रूसी (Русская версия)
- स्पेनिश (Versión en español)
- इतालवी (Versione italiana)
- फ्रेंच (Version française)
- जर्मन (Deutsche Version)
- अरबी (إصدار عربي)
- हिंदी (हिन्दी संस्करण)
- पोलिश (Polska wersja)
- वियतनामी (Phiên bản tiếng Việt)
- इंडोनेशियाई (Versi Bahasa Indonesia)

आप प्रत्येक भाषा के लिए GitHub रिपॉजिटरी भी देख सकते हैं, जहां एप्लिकेशन के बारे में अधिक विस्तृत दस्तावेज़ीकरण उपलब्ध है।
