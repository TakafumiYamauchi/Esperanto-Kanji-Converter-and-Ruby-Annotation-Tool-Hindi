# एस्पेरान्तो पाठ का कान्जी तथा HTML रूबी एनोटेशन टूल - उपयोगकर्ता मार्गदर्शिका

## परिचय

यह ऐप्लिकेशन एस्पेरान्तो पाठ को कान्जी (चीनी अक्षर) या HTML रूबी एनोटेशन में परिवर्तित करने के लिए एक शक्तिशाली टूल है। इसके द्वारा आप एस्पेरान्तो शब्दों और वाक्यों को आसानी से विभिन्न प्रारूपों में बदल सकते हैं, जिससे एस्पेरान्तो सीखने वालों के लिए पाठ अधिक सुलभ और समझने योग्य हो जाता है।

### मुख्य विशेषताएँ:

1. **विविध आउटपुट प्रारूप**: HTML रूबी एनोटेशन, कोष्ठक प्रारूप, सरल प्रतिस्थापन आदि
2. **फ़ॉन्ट आकार समायोजन**: HTML रूबी फ़ॉर्मेट में स्वतः फ़ॉन्ट आकार समायोजन
3. **कस्टम JSON समर्थन**: अपने स्वयं के प्रतिस्थापन नियमों को JSON फ़ाइल के माध्यम से उपयोग करें
4. **समानांतर प्रसंस्करण**: बड़े पाठों के लिए उन्नत समानांतर प्रसंस्करण
5. **आंशिक प्रतिस्थापन**: चिह्नित खंडों का आंशिक प्रतिस्थापन या प्रतिस्थापन से बचाव
6. **JSON जनरेटर**: अपनी कस्टम प्रतिस्थापन JSON फ़ाइल तैयार करें

1. **JSON फ़ाइल लोडिंग विकल्प**

6. **प्रतिस्थापन परिणाम क्षेत्र**
7. **अन्य भाषा संस्करणों के लिंक**

## प्रतिस्थापन JSON फ़ाइल का उपयोग

प्रतिस्थापन JSON फ़ाइल एस्पेरान्तो शब्दों को कैसे बदला जाएगा, इसके नियम निर्धारित करती है। इसके दो विकल्प हैं:

### 1. डिफ़ॉल्ट JSON का उपयोग करें
```
डिफ़ॉल्ट JSON फ़ाइल को लोड करने के लिए "डिफ़ॉल्ट JSON का उपयोग करें" विकल्प चुनें।
```

### 2. फ़ाइल अपलोड करें
```
अपनी कस्टम JSON फ़ाइल का उपयोग करने के लिए "फ़ाइल अपलोड करें" विकल्प चुनें और अपनी JSON फ़ाइल अपलोड करें।
```

### नमूना JSON डाउनलोड
आप "नमूना JSON फ़ाइल (रिप्लेसमेंट के लिए) डाउनलोड करें" एक्सपैंडर को क्लिक करके एक नमूना JSON फ़ाइल डाउनलोड कर सकते हैं, जिसे अपनी आवश्यकताओं के अनुसार संशोधित कर सकते हैं।

## उन्नत सेटिंग

"उन्नत सेटिंग्स (पैरलल प्रोसेसिंग)" एक्सपैंडर के अंतर्गत आप समानांतर प्रसंस्करण को सक्षम कर सकते हैं, जो बड़े पाठों की प्रोसेसिंग को तेज करता है।

### समानांतर प्रसंस्करण
```
- "पैरलल प्रोसेसिंग का उपयोग करें" चेकबॉक्स को सक्षम करें
- "समकालिक प्रोसेस की संख्या" को 2 से 4 के बीच सेट करें (अधिक प्रोसेस = अधिक तेज, लेकिन अधिक CPU उपयोग)
```

## आउटपुट प्रारूप

आप प्रतिस्थापित पाठ के लिए विभिन्न प्रारूप चुन सकते हैं:

1. **HTML फॉर्मेट, रुबी एनोटेशन और आकार समायोजन के साथ**: रूबी टैग के साथ HTML आउटपुट, स्वचालित फ़ॉन्ट आकार समायोजन के साथ
2. **HTML फॉर्मेट, रुबी एनोटेशन, आकार समायोजन और कान्जी प्रतिस्थापन**: ऊपर के समान, लेकिन मूल टेक्स्ट और रूबी अनोटेशन की स्थिति उलट जाती है
3. **HTML फॉर्मेट**: सामान्य HTML रूबी टैग के साथ
4. **HTML फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: मूल टेक्स्ट और रूबी अनोटेशन की स्थिति उलटी होती है
5. **कोष्ठकों वाला फॉर्मेट**: शब्द के बाद कोष्ठकों में रूबी दिखाता है (पाठ(रूबी))
6. **कोष्ठकों वाला फॉर्मेट (कान्जी प्रतिस्थापन के साथ)**: मूल टेक्स्ट और रूबी अनोटेशन की स्थिति उलटी होती है (रूबी(पाठ))
7. **केवल बदला हुआ पाठ रखें (सरल प्रतिस्थापन)**: केवल प्रतिस्थापित अक्षर दिखाता है, बिना किसी रूबी के

## इनपुट पाठ दर्ज करना

### इनपुट पाठ का स्रोत
आप निम्न में से एक विधि चुन सकते हैं:

1. **मैन्युअल इनपुट**: टेक्स्ट एरिया में सीधे टाइप करें
2. **फ़ाइल अपलोड**: UTF-8 एनकोडिंग के साथ एक .txt, .csv, या .md फ़ाइल अपलोड करें

### विशेष अक्षरों का प्रारूप
एस्पेरान्तो विशेष अक्षरों को दिखाने के लिए तीन प्रारूप हैं:

1. **अक्षर के ऊपर संकेत (ĉ → c + ˆ)**: विशेष अक्षरों को सर्कमफ्लेक्स के साथ दिखाता है
2. **x फॉर्मेट (ĉ → cx)**: विशेष अक्षरों को x के साथ दर्शाता है
3. **^ फॉर्मेट (ĉ → c^)**: विशेष अक्षरों को ^ के साथ दर्शाता है

### विशेष प्रतिस्थापन नियंत्रण
आप प्रतिस्थापन को विशेष प्रकार से नियंत्रित कर सकते हैं:

- **% वाला पाठ**: `%<50 अक्षरों तक का पाठ>%` के रूप में पाठ को चिह्नित करने पर वह पाठ प्रतिस्थापन से नहीं बदलेगा
- **@ वाला पाठ**: `@<18 अक्षरों तक का पाठ>@` के रूप में पाठ को चिह्नित करने पर वह पाठ केवल आंशिक/स्थानीय तौर पर बदलेगा

### फॉर्म बटन
```
- "सबमिट" बटन दबाएँ: प्रतिस्थापन प्रक्रिया शुरू करें
- "रद्द करें" बटन दबाएँ: प्रक्रिया रद्द करें और रिसेट करें
```

## प्रतिस्थापन परिणाम

प्रतिस्थापन प्रक्रिया पूरी होने के बाद, परिणाम इस प्रकार प्रदर्शित होगा:

### HTML फॉर्मेट के लिए
दो टैब दिखेंगे:
1. **HTML पूर्वावलोकन**: प्रतिस्थापित पाठ का लाइव प्रीव्यू
2. **परिणाम (HTML कोड)**: HTML कोड (कॉपी करने के लिए)

### अन्य फॉर्मेट के लिए
एक टैब दिखाई देगा:
1. **परिणामी पाठ**: प्रतिस्थापित टेक्स्ट

### डाउनलोड विकल्प
आप "परिणाम डाउनलोड करें" बटन दबाकर परिणाम को HTML फ़ाइल के रूप में डाउनलोड कर सकते हैं।

## JSON फ़ाइल जनरेटर टूल

ऐप का दूसरा पेज (पृष्ठ) आपको अपनी प्रतिस्थापन JSON फ़ाइल बनाने की अनुमति देता है। इस पेज तक पहुंचने के लिए साइडबार में "एस्पेरान्तो पाठ को स्ट्रिंग (कांजी) से प्रतिस्थापित करने हेतु JSON फ़ाइल बनाने का पृष्ठ" पर क्लिक करें।

### कार्य प्रवाह

1. **CSV फ़ाइल की तैयारी**:
   - अपनी स्वयं की CSV अपलोड करें या डिफ़ॉल्ट का उपयोग करें
   - CSV फ़ाइल में एस्पेरान्तो शब्दमूल और उनके अनुवाद/कान्जी प्रतिस्थापन होते हैं

2. **JSON फ़ाइल तैयार करें**:
   - शब्दमूल विखंडन नियम वाली JSON फ़ाइल अपलोड करें या डिफ़ॉल्ट चुनें
   - प्रतिस्थापित होने वाले टेक्स्ट की JSON फ़ाइल अपलोड करें या डिफ़ॉल्ट चुनें

3. **उन्नत सेटिंग** (वैकल्पिक):
   - बड़े डेटासेट के लिए समानांतर प्रोसेसिंग सक्षम करें

4. **फ़ाइल जनरेट करें**:
   - "प्रत्यस्थापन JSON फ़ाइल तैयार करें" बटन दबाएँ
   - जनरेट की गई JSON फ़ाइल डाउनलोड करें

### आउटपुट प्रारूप चयन

इस पेज पर भी आप आउटपुट प्रारूप चुन सकते हैं, जो मुख्य पेज के समान ही हैं। यह आपकी JSON फ़ाइल में परिभाषित प्रतिस्थापन प्रारूप को निर्धारित करेगा।

### नमूना फ़ाइलें

इस पेज पर "नमूना फ़ाइलों की सूची (डाउनलोड)" एक्सपैंडर के अंतर्गत कई नमूना फ़ाइलें उपलब्ध हैं:

1. **नमूना CSV फ़ाइलें**: एस्पेरान्तो शब्दमूल-हिंदी अनुवाद, चीनी अक्षर संगतता, आदि
2. **नमूना JSON फ़ाइलें**: शब्द विखंडन नियम, प्रतिस्थापन बाद का टेक्स्ट, आदि
3. **नमूना Excel फ़ाइलें**: विभिन्न भाषाओं में एस्पेरान्तो शब्दमूल और रूबी टिप्पणियां

## उपयोग के सुझाव और विशेष सिंटैक्स

### % और @ सिंटैक्स का उपयोग

1. **% का उपयोग**: यदि आप एस्पेरान्तो पाठ के कुछ हिस्सों को अपरिवर्तित रखना चाहते हैं:
   ```
   La floro estas %tre bela% kaj verda.
   ```
   यहां "tre bela" प्रतिस्थापित नहीं होगा, लेकिन बाकी पाठ होगा।

2. **@ का उपयोग**: यदि आप किसी खंड को केवल आंशिक रूप से प्रतिस्थापित करना चाहते हैं:
   ```
   La floro estas @tre bela@ kaj verda.
   ```
   यहां "tre bela" का प्रतिस्थापन विशेष रूप से (स्थानीय रूप से) किया जाएगा।

### बड़े पाठों के लिए सुझाव

1. **पैरलल प्रोसेसिंग का उपयोग करें**: 1000+ शब्दों के पाठ के लिए पैरलल प्रोसेसिंग सक्षम करें
2. **फ़ाइल अपलोड का उपयोग करें**: बड़े पाठों के लिए मैन्युअल टाइपिंग के बजाय टेक्स्ट फ़ाइल अपलोड करें
3. **HTML आउटपुट का उपयोग करें**: बड़े परिणामों के लिए HTML प्रारूप अधिक पठनीय हो सकता है

### कस्टम JSON बनाना

1. **अपनी CSV तैयार करें**: एस्पेरान्तो शब्दमूल (पहला कॉलम) और हिंदी/कान्जी अनुवाद (दूसरा कॉलम) के साथ
2. **विखंडन नियम समझें**: शब्दमूल विखंडन JSON में "dflt" और "verbo_s1" जैसे विशेष कीवर्ड का उपयोग करें
3. **प्राथमिकता निर्धारित करें**: प्रतिस्थापन के लिए शब्द प्राथमिकता संख्या निर्धारित करें (बड़ी संख्या = उच्च प्राथमिकता)
